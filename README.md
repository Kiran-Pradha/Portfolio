# Kiran Pradha Portfolio

A modern, responsive personal portfolio website built for showcasing education, experience, technical skills, projects, certifications, and contact information.

## Overview

This project is a polished single-page portfolio for Kiran Pradha M S, featuring:

- A forest-inspired visual theme with animated background particles
- Smooth scroll navigation and mobile-friendly menu
- Sections for About, Experience, Skills, Projects, Certifications, and Contact
- Downloadable resume button
- Project cards with links to GitHub repositories

## Live Preview

You can open the site locally by launching the `index.html` file in a browser, or serve it through a simple local server.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts
